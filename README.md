# ПОДВАЛ

Roguelike про спуск в недра хрущёвки. Восемь этажей вниз, пермасмерть, крысы, гопники, бабки, Дворник и Управдом.

Играть: https://ifonpromax.github.io/podval/

## Что внутри
- 4 персонажа со своей способностью (F): Васян («С ноги»), Дед Михалыч («Стоять!»), Студент Лёха («Рывок»), Кот Барсик («Шипение», уворот, запасная жизнь).
- 13 видов врагов, два босса, ларёк тёти Зины на чётных этажах.
- Ловушки: оголённый провод, скрипучая половица, открытый люк (проваливаешься на этаж ниже).
- Забег сохраняется сам: закрыл, потом нажал «Продолжить».
- «Забег дня»: у всех одно и то же подземелье на сегодня, можно меряться счётом.
- История забегов, кнопка «Поделиться», миникарта (Tab), синтезированный звук, вибрация в Telegram.

## Управление
- Комп: WASD / стрелки / нумпад, QEZC по диагонали, пробел ждать, Enter спуск, F способность, I рюкзак, X обшарить этаж, 1-9 предметы, Tab миникарта, M звук.
- Телефон: тап по клетке идти, свайп шаг, тап по себе ждать, кнопки снизу.

Чистый HTML + canvas, без зависимостей. Пиксель-арт нарисован кодом (`js/core.js`).

Дев-режим: `index.html?dev=1` подгружает `js/bot.js` с автоигроком (`bot(n)`, `botRuns(k, 'barsik')`) для проверки баланса.
