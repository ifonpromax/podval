# ПОДВАЛ

Roguelike про спуск в недра хрущёвки. Восемь этажей вниз, пермасмерть, крысы, гопники, бабки, Дворник и Управдом.

Играть: https://ifonpromax.github.io/podval/

- Чистый HTML + canvas, без зависимостей. Пиксель-арт нарисован кодом (`js/core.js`).
- Управление: WASD / стрелки / нумпад, QEZC по диагонали, пробел ждать, Enter спуск, I рюкзак, X обшарить этаж, 1-9 предметы.
- На телефоне: тап по клетке идти, свайп шаг, тап по себе ждать.
- Открывается и как Telegram mini-app (есть вибрация на ударах).

Дев-режим: `index.html?dev=1` подгружает `js/bot.js` с автоигроком (`bot(n)`, `botRuns(k)`) для проверки баланса.
